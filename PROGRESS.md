## Заметки для следующих чатов

- Команды npm в этом окружении запускать через `npm.cmd` (PowerShell блокирует npm.ps1).
- TypeScript 7 не сохраняет проверки «не null» внутри функций — в `main.ts` для этого helper `must()`.
- Порт 5173 периодически занят — вероятно, остаточный dev-сервер от прошлых сессий; Vite сам возьмёт 5174.
- Bitmap canvas соответствует content-box: размер брать через `clientWidth` (а не `getBoundingClientRect().width` — он включает рамку), иначе рисование и попадание по клеткам расходятся на толщину border.
- Открытые вопросы проекта — в `BACKLOG.md`.
